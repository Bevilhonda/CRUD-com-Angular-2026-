# CrudAngular

Este projeto foi desenvolvido para fins de aprendizado, implementando um CRUD (Create, Read, Update, Delete) robusto utilizando as funcionalidades mais modernas do ecossistema Angular.

Este projeto foi gerado com o Angular CLI na versão 21.0.4.

🚀 Tecnologias e Funcionalidades
Para este CRUD, as seguintes tecnologias foram selecionadas:

Angular 21: Uso de Standalone Components e Signals para gerenciamento de estado reativo e performático.

Vitest: Framework de testes unitários ultra-rápido, substituindo o Karma.

TypeScript: Tipagem estática para maior segurança no desenvolvimento.

RxJS: Gerenciamento de fluxos de dados assíncronos.

Angular Router: Navegação entre as telas de listagem, criação e edição.

🛠️ Servidor de desenvolvimento
Para iniciar um servidor de desenvolvimento local, execute:

ng serve
Assim que o servidor estiver rodando, abra seu navegador em http://localhost:4200/. A aplicação será recarregada automaticamente sempre que você modificar qualquer um dos arquivos de origem.

🏗️ Geração de código (Scaffolding)
O Angular CLI facilita a criação de novos arquivos. Para gerar um novo componente, execute:

ng generate component nome-do-componente
Para uma lista completa de comandos disponíveis (como directives, pipes ou services), execute:

ng generate --help

📦 Compilação (Build)
Para compilar o projeto para produção, execute:

ng build
Os arquivos finais serão armazenados no diretório dist/. O build de produção é automaticamente otimizado para performance.

🧪 Testes
Testes Unitários
Este projeto utiliza o Vitest. Para rodar os testes, use:

ng test
Testes de Ponta a Ponta (e2e)
Para rodar testes de interface (e2e), execute:

ng e2e
Nota: Verifique se você instalou um framework compatível (como Playwright ou Cypress) para esta funcionalidade.
